# Writing your own JARVIS skills

Every `.md` file in this folder (`~/.jarvis/skills`) teaches JARVIS a routine.
Files whose names start with `_`, like this one, are ignored.

A skill is just plain English:

1. **When**: the words that should trigger it.
2. **Steps**: what JARVIS should do, using the things he can already do
   (open or quit apps, volume, music, timers, reminders, memory, weather,
   web search, and showing things on his screen).
3. **Say**: how he should confirm it.

Save the file, then reload the JARVIS page. A restart isn't needed.

Up to 20 skills are read, about 2,000 characters each.
